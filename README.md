# Bank Loan Analysis Dashboard – Power BI

## Project Overview
The Bank Loan Analysis Dashboard is a data analytics project developed using Microsoft Power BI. The main objective of this project is to analyze bank loan data and provide meaningful insights into loan applications, loan performance, and repayment activities.

The dashboard helps understand the overall lending performance through interactive visualizations and key performance indicators (KPIs).

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Key Features
- Analysis of total loan applications.
- Tracking of completed and ongoing loans.
- Analysis of average interest rates.
- Monitoring recovered and outstanding loan amounts.
- Interactive dashboards for exploring loan performance.
- Data visualization using charts, graphs, and KPI cards.

## Key Performance Indicators (KPIs)
- Total Loan Applications
- Completed Loans
- Average Interest Rate
- Total Recovered Amount
- Outstanding Loan Amount

## Project Workflow
1. Imported bank loan data into Power BI.
2. Cleaned and transformed the dataset using Power Query.
3. Created calculated measures using DAX.
4. Designed interactive dashboards.
5. Analyzed loan performance and repayment-related metrics.
